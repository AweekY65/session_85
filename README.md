# Local 2D Particle Filter Localization Simulator

A self-contained 2D particle filter (Monte Carlo localization) simulator.
All maps, particles, sensor observations, trajectories and results live in
local memory or local files only — **no ROS, no robot hardware, no map
server, no external services**. All test data is generated by code.

## Layout

- `particle_filter/particle_filter.py` — core filter (motion update,
  likelihood weighting, normalization + degeneracy recovery, resampling,
  ESS, angle wrapping, state save/restore).
- `particle_filter/simulator.py` — synthetic data generation: landmark
  map, ground-truth trajectory, controls, noisy observations.
- `run_simulation.py` — demo run; writes `results/results.npz`
  (landmarks, ground truth, estimates, errors) and
  `results/final_state.pkl` (filter state snapshot).
- `tests/test_particle_filter.py` — automated tests.

## Motion model

State per particle: `(x, y, theta)`. Control input: `(v, omega)`
(linear velocity, yaw rate) with `dt`. Zero-mean Gaussian noise
(configurable `motion_noise=(std_v, std_omega)`) is added to the
commanded velocities per particle. Integration uses the exact arc
solution for non-zero turn rate and a straight-line limit otherwise;
headings are wrapped to `(-pi, pi]` after every update.

## Observation model

Landmark-based likelihood. Each observation is a range, or a
`[range, bearing]` pair, to a known landmark. Per-landmark Gaussian
log-likelihoods are accumulated in **log space**; the maximum
log-weight is subtracted before exponentiation (stable softmax), which
prevents probability underflow. Bearing residuals are wrapped before
squaring.

If all weights degenerate to zero (e.g. non-finite log-likelihoods),
an explicit recovery strategy runs: weights are reset to uniform and
small pose jitter is injected to restore particle diversity.

## Resampling

- **Systematic** (default) and **stratified** resampling are supported
  (`resample_method="systematic" | "stratified"`).
- Resampling is triggered only when the effective sample size
  `ESS = 1 / sum(w^2)` falls below `ess_threshold * N`.

## Angle wrapping

Headings are wrapped to `(-pi, pi]` everywhere. The pose estimate uses
the circular (vector) mean `atan2(sum(w*sin), sum(w*cos))`, so
particles near `+/-pi` average correctly instead of collapsing to ~0.

## Determinism and state persistence

- Every random source is a seeded `numpy.random.Generator`
  (`seed=` on `ParticleFilter` / `Simulator`); identical seeds reproduce
  identical results.
- `ParticleFilter.save_state(path)` / `ParticleFilter.load_state(path)`
  persist particles, weights and the full RNG state to a local file, so
  a restored filter continues deterministically.

## Running

```bash
python3 run_simulation.py     # demo, prints errors, writes results/
pytest tests/ -s -q           # tests; -s shows printed localization errors
```

Tests cover: stationary robot, constant-velocity motion, noisy
range-only observations, systematic + stratified resampling with ESS
thresholds, weight-degeneracy recovery, heading wrap near `+/-pi`,
fixed-seed determinism, and state save/restore reproduction. All tests
print localization errors and assert on them; no visualization windows
are used.
