# Local 2D Particle Filter Localization Simulator

A fully local 2D Monte-Carlo (particle filter) localization simulator in pure
Python + NumPy. All maps, particles, sensor observations, trajectories and
results live in memory or local files only — **no ROS, no robot hardware, no
map server, no external services**. All test data is generated by code.

## Layout

- `particle_filter/models.py` — motion model, observation models, angle helpers
- `particle_filter/filter.py` — `ParticleFilter`: weighting, normalization,
  resampling, ESS, save/restore
- `particle_filter/simulation.py` — synthetic landmarks, trajectories, noisy
  controls and observations
- `tests/test_particle_filter.py` — automated scenarios (terminal output only)

## Motion Model

Particles are poses `(x, y, theta)`. A velocity motion model applies the
control `u = (v, omega)` over a step `dt` with additive Gaussian noise
`(std_v, std_omega)`:

```
theta' = wrap(theta + (omega + n_omega) * dt)
x'     = x + (v + n_v) * dt * cos(theta + omega*dt/2)
y'     = y + (v + n_v) * dt * sin(theta + omega*dt/2)
```

The translation is integrated along the mid-step heading (2nd-order
approximation). Headings are always wrapped to `(-pi, pi]` via `wrap_to_pi`,
and pose estimates use a **circular (vector) mean**, so particles clustered
near `+/-pi` average to the correct direction instead of ~0.

## Observation Model

Against a known landmark map the filter supports:

- **Range-only**: `z = ||landmark - pose|| + noise`
- **Range + bearing**: `z = (range, wrap(bearing_global - theta)) + noise`

Both use Gaussian likelihoods. Likelihoods are accumulated in **log-space**
(`log_w += log N(z; z_hat, sigma)`), then shifted by the maximum log-weight
before `exp()` — a numerically stable scheme that avoids probability
underflow. If all weights still degenerate to zero (e.g. physically
impossible observations), the filter applies an explicit **recovery
strategy**: weights are reset to uniform and the event is counted in
`pf.degeneracy_events`.

## Resampling

- **Effective sample size** `ESS = 1 / sum(w^2)`; resampling triggers when
  `ESS < ess_threshold * N` (default threshold 0.5).
- Two algorithms, selectable via `resample_method`:
  - `systematic` (default): one uniform draw + evenly spaced offsets.
  - `stratified`: one independent uniform draw per stratum.
- After resampling, weights are reset to uniform.

## Determinism, Save / Restore

- `ParticleFilter(seed=...)` fixes a `numpy.random.Generator`; identical
  seeds reproduce runs bit-for-bit.
- `pf.save_state(path)` pickles particles, weights, config and the full RNG
  state to a local file; `ParticleFilter.load_state(path)` resumes
  deterministically — a restored filter reproduces an uninterrupted run
  exactly (verified by tests).

## Running the Tests

```bash
python -m pytest tests/ -s
```

`-s` shows the per-scenario terminal output: each test prints the estimated
pose, ground truth, position/heading error with tolerances, and the assertion
result. No visualization windows are used.

Covered scenarios: stationary robot, constant-velocity motion, noisy
observations, range-only observations, systematic & stratified resampling,
ESS threshold logic, all-zero weight degeneracy recovery, heading wrap
across `+/-pi`, fixed-seed reproducibility, and state save/restore.
